# Memory Match

A simple browser memory game with difficulty levels, theme-based cards and sounds, a timer, progress bar, particles, stories, and a local top-five leaderboard.

## Run

Open [index.html](./index.html) in a modern browser. No build step or dependencies are required.

## Structure

- `index.html` - Main page
- `css/style.css` - Game styling
- `js/game.js` - Main game logic
- `js/storage.js` - Local leaderboard storage
- `js/ui.js` - Shared UI helpers
- `images/cards/` - Optional card images
